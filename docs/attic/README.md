# Attic — eingelagerte Konzept- und Programm-Docs (2026-07-28)

First-principles-Reset (Owner-Entscheid): dieses Projekt ist eine **Harness für Claude Code** —
sehen, senden, spawnen, landen, loslassen — und nicht mehr. Hier liegt die Ideation-Schicht,
die darüber hinausgewachsen war: das Autonomie-/Graduierungs-Programm (K-Serien, Shadow-Judge,
graduation-criteria), das Steward-Universum jenseits der Betriebs-Konvention, datierte
Analyse-Snapshots und Pläne.

Nichts hier ist gelöscht: alles bleibt lesbar und per `git mv` reaktivierbar, falls die
Autonomie-Frage je wieder gestellt wird (die Datenlage dafür wächst passiv weiter im
lane-outcomes-Ledger). Aber nichts hier fordert Pflege, erzeugt Regeln oder bindet
Aufmerksamkeit. Betriebswissen lebt eine Ebene höher in `docs/` und in `CLAUDE.md`.
