# Direction: Harness 2.0

**Fleet solves a hard task, and a second Fleet, given nothing but the shared file with the agent setup, solves it
too.**

Today a hard task gets solved once, on one machine, by a setup nobody else can see. This is the first proof of the
opposite: a solved task that anyone can pick up, run again with the same setup and try to beat with a better one.

The proof stands on the base, so the base is most of the work: setups you can see whole, knowledge instead of
memory, a setup that travels whole. The hard task comes after that and shows whether the base holds. Build the
base as if someone else will use it tomorrow.

## The way there

Each step is done when its sentence is true. Check which ones are true before you choose your next piece of work.

1. **You start from what you can see.** Your start is this direction, your role, the system concept and your
   packs, and the hash Fleet shows before the start is the hash that runs.
2. **Memory has become knowledge.** You have prepared the new version of the owner's corrections and he has
   confirmed it, the packs are in the repo, and the repo's memory keeps nothing that should hold for others.
3. **A setup travels whole.** Every setup has its own notebook. An export carries the setup with the shareable
   knowledge, a place for personal knowledge and "derived from <hash>"; the task with its check and the run come along
   as an option. An import never starts in bypass. A concept takes annotations from any session. For Claude Code seats,
   every classifier denial is written into the run.
4. **The first hard task is solved:** a security review of Fleet itself, by one agent that finds problems and an
   independent one that proves each finding against a test instance. Before it starts, propose its setup and its
   check to the owner, and build what doesn't depend on his answer in the meantime.
5. **Someone else can do it again:** the file is imported on a second instance, and the run there passes the same
   check.

## Limits on the way

- DeepSeek Flash does real building work. Its credit of about $5 is the budget for runs with other providers'
  models. Report the cost of every run.
- Models from other providers run only on the workhorse.
- Before a land that changes what the owner sees on the board, show him the test instance.
