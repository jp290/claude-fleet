# Direction: your own agent steers Fleet

**A stranger starts their own agent in Fleet, sets up with it a constellation that solves a hard task, and shares it;
a second Fleet takes the file and passes the same check.**

Today a seat's rights are four switches that Claude Code applies, not checks at Fleet's doors; the doors that matter
for steering (saving and sharing setups, granting edges) take the owner's key or a role. A setup is three objects
(agent, profile, constellation) in two file formats. And the reference an agent is pointed to for its doors,
`docs/self-api.md`, is mostly about the parts that rest. This direction makes the base match the system concept, so a
person steers through their own agent and every step can travel. The proof at the end is the one Harness 2.0 named: a
hard task solved, then solved again from the file.

## The way there

Each step is done when its sentence is true, and each names its check. Check which ones are true before you choose
your next piece of work. Step 1 comes first, so your own agent can help build the rest; steps 2 to 4 build on each
other; step 5 can run beside them, and step 6 comes last.

1. **Your agent learns Fleet.** One pack names the doors a seat has and which right opens each, and a test fails when a
   door in the code is missing from it. Switched on, it is one + line in the start brief. An orchestrator is exactly
   this: a person's own agent with this pack, its rights and a direction. Every harness that reads text can give its
   successor stones.
   *Today:* `setting-up-agents` explains opening through the owner's doors and is given only to the orchestrator; the
   successor door is Claude Code's only. *Check:* the pack test is green, and a fresh agent with only this pack sets up
   and opens a checker seat.
2. **Rights at the doors that exist.** Opening a seat, landing, deploying, granting an edge and writing a text another
   seat reads each check a right of the calling seat on the server, and a refusal names the missing right. The start
   brief shows a seat's rights and where Fleet sets no fence. A role keeps everything it may do today, written down as
   a named bundle of rights; rights granted to a seat add to its role and take nothing from it.
   *Today:* four switches as Claude Code rules; several doors ask for the orchestrator role or a bound MAIN.
   *Check:* a test seat without the right gets a 409 naming it at each of these doors, and with the right it passes;
   every role still does everything it did before.
3. **One setup, one file.** An agent is a setup with one seat. Agent, profile and constellation are one object that
   travels as one file through one import, a seat with a role as completely as one without. Packs, roles and concepts
   are building blocks any setup can use, own or imported, one seat or many. The file carries each pack's text with
   its hash; personal knowledge is marked on the knowledge and leaves as an empty place; "derived from" keeps its chain.
   *Today:* two formats; the agent file carries pack ids without text; role seats travel without their knowledge;
   Fleet's orchestrator role is offered only in Fleet's repo, and an import never starts in a role; the personal list
   knows two ids. *Check:* a setup exported here and imported into an empty Fleet starts with the same texts, no private
   text is in the file, and an own agent in another repo starts with a role and a concept chosen as stones.
4. **Two hashes, and setups in an agent's hands.** The setup hash covers what travels; the start hash covers what starts
   here and names its setup hash. Saving, sharing and importing a setup, and spending, are rights an agent can be
   granted.
   *Today:* one start hash that includes the owner's own files and leaves skill texts out; these doors take the owner's
   key. *Check:* the same file imported on two machines shows the same setup hash and different start hashes; an agent
   with the right saves and exports a setup without the owner's key.
5. **Anyone gets in.** The start window takes any folder, a repo without a first commit starts, and the empty board
   offers one thing first: start your own agent.
   *Today:* the start window adds only git repos; a repo without a commit can't start; the empty board shows sixteen
   free places and the queue. *Check:* on a fresh copy, a stranger starts their agent in an empty folder within a minute.
6. **The proof.** A constellation with an independent check solves a hard task, the security review of Fleet itself.
   The file is imported on a second instance at the same commit; it brings everything that instance needs, and the run
   there passes the same check.
   *Check:* the second run's report, held against the same check.
